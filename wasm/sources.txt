# sukkal's own C sources that compile for WASM, one per line, relative to
# the package root. Consumed by build-wasm.sh.
#
# A file joins this list once it no longer reaches POSIX, http11c or
# libcurl directly — see docs/wasm-plan.md for the three seams and the
# order they get cut in.
#
# store.c reaches the world through a bj_ns and two host hooks (a clock
# and an atomic replace) and nothing else. Its POSIX half lives in
# src/store_posix.c, which is native-only and not listed here.
src/store.c
#
# server.c is the routing table and every handler, written against
# sukkal_req/sukkal_res. Its http11c half is src/server_posix.c.
src/server.c
#
# push.c decides what to deliver and what a failure means; the sending is
# a host transport (sukkal_transport). Its libcurl one is src/push_posix.c.
src/push.c
#
# bjtext.c is binjson <-> text and was always portable.
src/bjtext.c
#
# ...and the entry point that makes them reachable: the broker as a
# function call, with no transport in it at all.
src/sukkal_wasm.c
